# Roguelike — OOP with Java 1 (Re-exam)

A console roguelike with a status-effect system.

## Run

Open the `Re_exam_project` folder in VS Code and run `src/Main.java`.

## Tests

Open the Testing panel (flask icon) and run them, or click the green arrow next
to a test. The JUnit jar is in `lib/`.

## Controls

W / A / S / D move, U uses the first item, Q quits.
